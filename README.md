# Слух — помощник для разговора

PWA для слабослышащих и пожилых людей.
Телефон ставится в центр разговорной группы, звук обрабатывается
и передаётся в **один Bluetooth-наушник** собеседника.

## Что делает

- **Спектральное шумоподавление** (STFT, Wiener с over-subtraction)
- **Усиливает тихую речь** (адаптивный AGC)
- **Приглушает резкие звуки** (transient limiter)
- **Подчёркивает разборчивость** (presence 2–4 кГц)
- **Отсекает низкий гул** (highpass)
- **Плавно приглушает тихий фон** (шумовой гейт)
- **Мягкий лимитер** — защита от перегрузки

## Что нового в v0.2

- **Реальное спектральное шумоподавление** в `processor.js`:
  - STFT: N=512, hop=256, окно sqrt-Hann (COLA)
  - Оценка шума по минимум-статистике с bias correction
  - Wiener-усиление с over-subtraction (α = 1..4)
  - Межкадровое сглаживание усиления против «музыкального» шума
  - Spectral floor
- **Слайдер «Подавление шума»** 0..1 (0 = bypass)
- **Пресеты обновлены** с учётом NR

Латентность алгоритма ≈ 10.6 мс (при 48 кГц). Плюс задержка Bluetooth
(~100–250 мс — нормально для речи).

## Как пользоваться

1. Подключите Bluetooth-наушник к телефону.
2. Откройте приложение (или установите на домашний экран).
3. Поставьте телефон в центр стола.
4. Нажмите **«Начать слушать»**.
5. Разрешите доступ к микрофону.
6. Если слышен свист или эхо — **уменьшите громкость** или «усиление тихой речи».

## Важно

- Используйте **вкладыш** (не колонку) — иначе будет акустическая обратная связь.
- **Не медицинское изделие.** При потере слуха обратитесь к врачу.
- Используйте только с согласия всех участников разговора.

## Установка на GitHub Pages

1. Создайте репозиторий `listenboost` на GitHub.
2. Загрузите все файлы из этой папки.
3. Settings → Pages → Source: **Deploy from a branch** → `main` / `root`.
4. Откройте `https://<username>.github.io/listenboost/`.
5. В Chrome на Android: меню → **«Установить приложение»**.
