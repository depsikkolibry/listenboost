# Слух — помощник для разговора

PWA для слабослышащих и пожилых людей. Телефон — в центре разговорной группы,
микрофон — **телефона**, звук — в один Bluetooth-наушник пожилого человека.

## Что нового в v0.3

- **Выбор микрофона** — пикер с автовыбором микрофона телефона. Bluetooth-микрофон
  гарнитуры помечается «не рекомендуется» (это была причина «звук из наушника возвращается»).
- **`echoCancellation: true`** — системный AEC Android гасит остаточную акустическую петлю.
- **De-esser** — мягчит «с» / «ш» / «ц» в спектральной области.
- **VAD** — индикатор «Слышу речь» / «Тишина» на основе энергии в полосе 200–4000 Гц
  против шумовой полки.
- **Субтитры** — распознавание речи (`SpeechRecognition`), крупный шрифт,
  `aria-live` для скринридеров.
- **Визуализация** — waveform + логарифмический спектр.
- **Автопереключение микрофона** при подключении/отключении BT-гарнитуры.
- **Современный HTML**: `<details>`, container queries, `prefers-contrast`.

## Микшер и защита от петли

1. Подключите наушник-вкладыш.
2. В настройках убедитесь: выбран **«🎤 Микрофон …»**, а не **«🎧 …»**.
3. Поставьте телефон в центр стола, наушник — в ухо.
4. Громкость — начните с 1.5×.
5. Свист → уменьшить громкость или `Усиление тихой речи`.

## Установка на GitHub Pages

1. Создайте репозиторий `listenboost`.
2. Загрузите все файлы.
3. Settings → Pages → Deploy from branch → `main` / `/root`.
4. Откройте `https://<username>.github.io/listenboost/`.
5. Chrome на Android → меню → **«Установить приложение»**.
